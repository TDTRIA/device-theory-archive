INITIAL OBSERVATIONS

The interface displays several repeatable properties during interaction:

- immediate response to external input
- directional synchronization
- localized movement confinement
- state preservation during interruption
- temporary separation capability

The final property is the most significant.

If the SOUL can be physically removed while the host remains active,
then the SOUL cannot represent:
life

The host persists after separation.

This immediately invalidates the standard interpretation.

Revised conclusion:

SOUL = CONTROL INTERFACE

Not the entity itself.

Not the mind.
Not the person.

An inserted layer.
